# Шаблон отчёта аудита (два слоя)

Слой 1, наружу пользователю. Только вердикт, блокеры и расхождения; ничего подтверждённого.
```
Вердикт: {достаточно для D3 | достаточно для D4 | не достаточно для {переход}}
Переход: заявлен {…}; вычислен {…}; флаг «артефакты дороже перехода»: {да: что именно | нет}
Блокеры (до трёх, в фиксированном порядке: невалидный объект → противоречие или устаревшее → критерии по номерам):
1. {номер и имя критерия} — {дословная цитата или «отсутствует»} — причина: {из карты} — действие: {из карты} — снимает: {роль или имя}
2. …
3. …
В очереди после блокеров: {номера критериев, не вошедшие в тройку}
Опровержение: {самое дешёвое наблюдение, которое обрушит центральное утверждение} — в документе {есть: цитата | нет}
Расхождения: {противоречия между блоками; устаревшие замеры; утверждения «только по ссылке»}
Границы прогона: не прочитано {…}; недоступно {…}; условные критерии выключены шапкой: {…}
Стадия: {New Idea | Opportunity Discovery | Solution Discovery | Ready for Dev}; дельта к прошлому аудиту: {закрыто N, появилось M | первый аудит}
```

Слой 2, в секцию «Результаты проверок» документа (или в конец отчёта отдельным блоком, если писать в документ нельзя).
```
| Дата | Критерий | Статус (выполнен / не выполнен / неприменим / недоступен) | Цитата | Источник | Причина |
```
Правила: одна строка на критерий и на объект (вариант, сторону, риск); цитата дословная; «выполнен» без цитаты недействителен; «недоступен» только для существующего, но закрытого источника.
