# Карта «причина → минимальное действие»

Действие пишется в блокер дословно из этой карты, чтобы не плыть между прогонами. Кто снимает: по умолчанию автор документа; иначе указано.

| Причина | Что это значит | Минимальное действие | Кто снимает |
|---|---|---|---|
| Отсутствует | Нет строки, поля или таблицы; «не замеряем», «данных нет» | Добавить строку или поле {имя} по шаблону assets/document-skeleton.md | автор |
| Не по форме | Раздел найден, но атомов не хватает: число без единицы или периода, порог буквой, составная ячейка, ссылка на пересказ | Дописать недостающие атомы: {единица, период, ссылка на первичный источник, цитата} | автор |
| Неоднозначно | Два кандидата там, где допустим один (две гипотезы, два числа потолка) | Оставить одну строку, разбивку перенести в Appendix | автор |
| Противоречие | Два значения одного показателя в разных местах | Свести к одному значению, указать источник и период, второе удалить или пометить устаревшим | автор |
| Источник недоступен | Ссылка есть, открыть нельзя | Открыть доступ или приложить выгрузку | автор или владелец источника |
| Не первичный источник | Ссылка ведёт на страницу с пересказом чисел | Заменить ссылкой на запрос, витрину, отчёт или транскрипт | автор |
| Цитата не найдена | В источнике нет вставленной строки результата | Вставить строку результата из источника дословно | автор |
| Устарело | Замер старше порога из шапки или сделан до существенного изменения | Обновить замер, указать дату | аналитик |
| Периоды не совпадают | Число потолка и текущее значение за разные периоды | Пересчитать оба за один период | аналитик |
| Объект без строки | В шапке назван сегмент, сторона, поверхность или команда, а строки для неё нет | Добавить строку для {объект} | автор |
| Нет подтверждения | Сторона с правом вето помечена «не спрашивали» или «отклонил», или ссылка ведёт на вопрос, а не на ответ | Получить ответ и вставить permalink на сообщение | автор, ответ даёт сторона |
| Арифметика не сходится | Цель не равна произведению трёх чисел, знак не совпадает с направлением | Пересчитать цель или исправить числа, записать формулу | автор |
| Интервалы не покрывают шкалу | В правиле остановки есть дыра, перекрытие или один интервал | Дописать интервалы так, чтобы любой результат попадал ровно в один | автор |
| Число «ложно» не в стоп-интервале | Первая проверка не может опровергнуть предположение | Изменить порог или интервалы так, чтобы «ложно» вело к стопу или смене варианта | автор |
| Дороже перехода | Первой проверкой назван A/B или пилот; при D3 в документе критерии приёмки, макеты, оценки, план раскатки | Заменить первую проверку дешёвой (запрос, ретро, разметка, прототип, интервью) или заявить D4 и пройти его набор | автор |
| Шапка противоречит таблицам | В шапке «нет», а в таблицах есть исключение, поверхность, KILL-риск | Исправить шапку или таблицу, поставить подпись, кто оценил | автор |
| Составной документ | Несколько нитей решений в одном документе | Разделить на нити или назвать одну для аудита | автор |
