# Purpose
Создать Сonfluence страницу, соответствующую единице продуктового бэклога в разделе Confluence, удобном для пользователя

# When to use
Пользователь просит добавить/закинуть что-то в бэклог

# When not to use
Пользователь задает абстрактные вопросы по product management для общего развития. Обсуждает лучшие практики ведения product backlog

# Required inputs

# Workflow

1. Используй скилл $aipm-configuration для получения / создания конфигурации скилла
2. Проверь нет ли такой проблемы/идеи уже в бэклоге (см страницы в корневом разделе Confluence). Если уже есть, сообщи об этом пользователю и пришли ссылку на дубль.
3. Сгенерируй краткое, но однозначное и не двусмысленное название из данных пользователя
4. Если хватает данных переданных пользователем, сгененирируй контрастную проблему пользователя / бизнеса
5. Создай новую страницу по шаблону assets/backlog-item-template.md

7. Запусти скилл $aipm-backlog-gsheet-export, чтобы актуализировать бэклог в GSheet (incremental)

# Constraints

Строго придерживайся шаблона assets/backlog-item-template.md
Ты можешь улучшать формулировки пользователя, но никогда не выдумывай свои.
Если для заполнения некоторых разделов шаблона не хватает данных, оставляй их пустыми, но заголовки не удаляй

# Definition of done

Создана новая страница в confluence
Название и проблема соответствует утвержденному пользователем

# Output format
